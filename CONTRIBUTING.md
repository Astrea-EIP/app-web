# Contributing to `app-web`

`app-web` follows the Astrea-EIP engineering handbook for all shared contribution rules.
Use the central handbook as the source of truth for workflow, branch naming, commit format, pull request requirements, and documentation policy.

## Required references

Read these handbook sections before opening a pull request:

- `contribution/getting-started`
- `contribution/git-workflow`
- `contribution/branches`
- `contribution/commits`
- `contribution/pull-requests`
- `contribution/documentation`

## Local rules

- Work only on web frontend concerns in this repository.
- Keep one pull request scoped to one issue.
- Update `docs/` when setup, architecture, or web behavior changes.
- Keep CI green before requesting review.
